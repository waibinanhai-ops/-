# 剪贴板管家 (ClipVault) — 开发需求文档

## 项目概述

一款运行在 macOS 上的菜单栏历史剪贴板管理工具，自动记录用户复制的文字和图片，支持查看、搜索、置顶、删除，可设置 1/3/5 天自动过期时间。

## 目标用户

- 不懂代码的普通 Mac 用户
- 经常需要查找之前复制过内容的用户

## 功能需求

### F1. 剪贴板监听
- 自动监听系统剪贴板变化
- 支持文字、图片、URL 三种类型
- 过滤系统远程剪贴板（Universal Clipboard）
- 过滤密码管理器复制的内容（检测隐藏标记）

### F2. 内容记录
- 文字内容：记录完整文本
- 图片内容：存储为 PNG 文件，数据库仅存路径
- 记录来源 App 名称
- 去重：连续复制相同内容只保留一条（SHA-256 哈希比对）
- 最多存储 10,000 条记录

### F3. 历史查看
- 菜单栏图标点击弹出面板
- 快捷键 Cmd+Shift+V 弹出面板
- 面板以浮动窗口形式展现，不抢夺当前 App 焦点
- 跨桌面/全屏 App 跟随显示
- 点击面板外部自动关闭
- 卡片按时间降序排列（最新在上），置顶卡片优先

### F4. 内容操作
- 点击卡片：重新复制到剪贴板，关闭面板
- 右键菜单：复制 / 置顶切换 / 查看详情 / 删除
- 文字卡片：预览 1-2 行文字
- 图片卡片：显示 200px 缩略图
- 点击图片可查看大图

### F5. 搜索功能
- 搜索框输入关键词
- 300ms 防抖
- 模糊匹配文字内容
- 结果混合显示文字和图片记录

### F6. 置顶功能
- 任意记录可置顶/取消置顶
- 置顶记录排在最前面，带图钉标记
- 置顶记录不受过期自动删除影响

### F7. 自动过期
- 用户可选：1 天 / 3 天 / 5 天
- 默认 3 天
- 每小时自动检查并删除过期记录
- 同时清理关联的图片文件

### F8. 开机启动
- 设置页提供开关
- 使用 SMAppService 实现

### F9. 设置项
- 保留天数选择：1 / 3 / 5 天
- 开机启动开关
- 清空所有历史（带确认对话框）

## 非功能需求

### N1. 性能
- 剪贴板轮询间隔 0.5 秒
- 面板打开需在 200ms 内响应
- 搜索在 300ms 防抖后即时响应
- 面板内列表滑动流畅（LazyVStack）

### N2. 隐私
- 所有数据仅存储在本地
- 不上传任何内容到网络
- 密码管理器内容自动过滤

### N3. 资源占用
- 内存常驻 < 50MB
- 图片存储上限 500MB（自动清理最旧）
- SQLite 数据库 < 10MB

### N4. 兼容性
- macOS 14 (Sonoma) 及以上
- 深色/浅色模式适配
- 多显示器支持
