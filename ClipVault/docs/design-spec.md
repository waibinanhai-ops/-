# 剪贴板管家 (ClipVault) — 设计规范

## 设计原则

- **简洁直观**: 减少视觉噪音，一目了然
- **高效操作**: 最少点击次数完成核心任务
- **低调融入**: 作为工具类 App，不过度抢眼

## 布局规范

### 面板
- 宽度: 380pt
- 高度: 500pt（可调整）
- 圆角: 12pt
- 内边距: 16pt（水平）

### 卡片
- 高度: 自适应（文字约 60pt，图片约 220pt）
- 内边距: 12pt
- 圆角: 8pt
- 卡片间距: 8pt
- 左侧类型图标: 20x20pt
- 右侧时间戳: 最多 80pt 宽

### 搜索框
- 高度: 32pt
- 圆角: 8pt
- 距离列表: 12pt

### 图标
- 菜单栏图标: 18x18pt（模板图，单色）
- 卡片类型图标: SF Symbol，20x20pt
- 操作按钮: SF Symbol，16x16pt

## 交互规范

### 卡片交互
- 单击: 复制内容到剪贴板 + 关闭面板
- 右键/长按: 弹出上下文菜单（复制/置顶/详情/删除）
- 悬停: 卡片背景色微变

### 面板交互
- 打开: 从菜单栏图标下方滑出（无动画即可）
- 关闭: 点击面板外部、按 Esc、再次点击图标
- 搜索: 输入时 300ms 防抖后即时筛选
- 滚动: 流畅无卡顿（LazyVStack 天然支持）

### 置顶交互
- 置顶卡片顶部显示 📌 图钉标记
- 置顶卡片有淡橙色左边框
- 右键菜单显示"取消置顶"或"置顶"

### 删除交互
- 从卡片右滑或右键菜单触发删除
- 删除操作无需二次确认（可恢复性低的数据直接删）
